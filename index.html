04 · Failure mode

The voice gap

The known way a citizen-feedback platform fails: it hears the connected and funds them, while silent districts with worse infrastructure stay invisible. Setu measures that gap explicitly instead of assuming it away.

Participation against need

Horizontal: how loudly a unit reports. Vertical: how badly it scores on the infrastructure deficit index. Bubble area: capital already committed per capita, in the display currency you select on the priority engine. The lower-right quadrant is where naive demand-ranking sends the money; the upper-left is where it should also go.

Units in the upper-left file few requests yet carry the worst deficits — the correction on the previous page is what lifts them into the recommendation list.

Most under-heard units

Expected requests (from population × deficit) minus observed requests, normalised.

What we do about it

  • Impute, then flag. Imputed demand never silently replaces real demand; the record carries an imputed:true field and the rank shows the uplift.
  • Actively sample. Units above a gap threshold trigger outbound IVR surveys in the local language, turning a passive channel into a stratified one.
  • Weight by census, not by traffic. Rates per 100k, never raw counts.
  • Publish the gap. The voice-gap table is part of the public dashboard, so a district can contest its own invisibility.
Honest limit: imputation assumes deficit indices are themselves unbiased. Where a census under-counts informal settlements, Setu inherits that error. Mitigation is ground-truthing against satellite-derived built-up area, which this prototype does not implement.
05 · Measurement

Did the money change anything?

A platform that only ranks is an opinion generator. Setu holds a matched-control design so a ministry can state, with evidence, whether units it funded on this advice improved faster than comparable units it did not.

Infrastructure deficit, funded cohort against matched controls

Units funded in the top decile of Setu's ranking, paired with units of similar baseline deficit, population band and sector mix that were not funded. Lower is better.

Illustrative design, not observed results. These curves show the evaluation this prototype is built to support; no real programme has been run through it. The number that matters is the gap at Q8, and it is only credible if the control group was matched before allocation, not selected afterwards.

Why matched controls, not before-and-after

  • Infrastructure improves anyway. A before-and-after chart credits the platform with every road the state would have built regardless.
  • Ranking creates selection. High-scoring units differ systematically from low-scoring ones, so the comparison group has to be built on baseline covariates, not convenience.
  • Pre-register the pairing. Matches are fixed and published before allocation, which is the only thing that stops a ministry from choosing flattering controls later.

Reported alongside every recommendation

Coverage and voice-gap variance are process metrics — they say the platform is being used fairly. Only the deficit gap says it worked.

06 · Engineering

Build and DPG posture

What exists in this prototype, what production needs, and why the design qualifies as a Digital Public Good rather than a vendor product.

Reference architecture

Channel
Asterisk IVR · WhatsApp Business API · SMS gateway · kiosk PWA. Voice matters most: it is the only channel that works for a non-literate citizen, and it is the one most platforms skip.
Understanding
Whisper-large-v3 for ASR, IndicTrans2 / NLLB-200 for pivot translation, a fine-tuned XLM-R classifier for sector, urgency and sentiment. All open weights, all self-hostable — a ministry can run the stack inside its own sovereign cloud.
Record
Append-only district ledger, open JSON schema, per-record provenance. PII is separated at ingest: the aggregation store holds a district code and an anonymous hash, never a phone number.
Fusion
Joins to census, the national infrastructure deficit index and published capital budgets. Deduplication clusters near-identical reports so one grievance filed 400 times counts as one issue with strength 400.
Console
React 19 + Next.js with React Three Fiber for the orbital view, served as a progressive web app. This prototype is a single dependency-free HTML file so it opens instantly from a link on any device; the production console is a component app against the same open API.
Decision
Transparent weighted scoring with published weights, latent-demand correction and plan-divergence reporting. No black-box ranking: a citizen can reconstruct why their district placed where it did.

Digital Public Good criteria

  • Open licence. AGPL-3.0 for the platform, CC-BY-4.0 for the schema and taxonomy.
  • Open standards. OpenAPI, ISO 3166-2 sub-national codes, SDG-aligned sector taxonomy.
  • Platform independence. No managed-cloud primitives; Postgres, object storage, containers.
  • Do-no-harm by design. PII split at ingest, data-minimised aggregation store, published scoring weights.
  • SDG relevance. Targets 6.1, 7.1, 9.1, 16.7 — the last one, responsive and participatory decision-making, is the direct one.

Status and next 30 days

  • Working now: multilingual lexicon triage, sector and urgency tagging, geotagged records, demand aggregation, the weighted priority engine, latent-demand correction, plan-divergence reporting.
  • Stubbed: ASR (samples are pre-transcribed), translation (pivot strings are fixed), dedup clustering.
  • Next: wire Whisper and NLLB behind the existing interface; validate the classifier against a hand-labelled set of 2,000 real grievances with per-language F1 reported separately, because an aggregate score would hide failure in low-resource languages; back-test the priority ranking against three years of completed projects to check whether high-scoring units actually showed larger outcome gains.

How we would know it worked

  • Coverage: share of districts filing at least 50 requests per 100k per quarter, and the voice gap's variance falling over time.
  • Classifier quality: macro-F1 per language, not pooled; a floor of 0.75 on the weakest language before any recommendation ships.
  • Alignment: rank correlation between Setu's order and the next budget cycle's actual allocations.
  • Outcome: change in the infrastructure deficit index in funded units against matched unfunded controls, 24 months out.

The fourth metric is the only one that proves the platform mattered. The first three are necessary conditions, not evidence of impact.
